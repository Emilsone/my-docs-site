# Overview

This documentation teaches you how to work with REST APIs using JavaScript. It is divided into two main sections: a hands‑on tutorial and an API reference.

The tutorial  shows you how to make your first API call using Axios in Node.js, while the reference section explains how to work with the GitHub REST API. 
 
The API Refrence gives you access to repositories, users, issues, and other GitHub resources via HTTP.

## What you will learn

By the end of this guide, you will be able to:

- Make your first API call using Axios in Node.js
- Understand how REST APIs work at a basic level
- Read and use API reference documentation
- Work with real data from the GitHub REST API

## Tutorial (Axios API Call)

The tutorial walks you through building your first API request from scratch using Axios. You will learn how to set up a Node.js project, send a GET request, and handle the response from an external API. In this tutorial, you’ll build a small Node.js script that fetches data from your GitHub profile.

## API Reference (GitHub REST API)

The reference section explains how to use the GitHub REST API. It shows you how to understand endpoints, request methods, parameters, and responses so you can confidently interact with real‑world APIs.

## Before you start

You should have:

- Basic knowledge of JavaScript
- Node.js installed on your machine
- A code editor (VS Code recommended)

No prior experience with APIs is required.
