
# API Reference 

## GitHub REST API

**Base URL:** `https://api.github.com`

---

## Endpoint 1 — Get a Repository

**HTTP Method:** `GET`

**URL:** `https://api.github.com/repos/Emilsone/Nasa-image`

**Description:** Returns detailed information about a single public GitHub repository, including its name, description, default branch, star count, fork count, open issue count, and visibility.

### Parameters

| Name  | In   | Type   | Required | Description                                                  |
| ----- | ---- | ------ | -------- | ------------------------------------------------------------ |
| owner | path | string | required | The username or organisation that owns the repository        |
| repo  | path | string | required | The exact name of the repository                             |

### Example Request

```http
GET https://api.github.com/repos/Emilsone/Nasa-image
```

### Error Codes

| Code | Name               | Meaning                                          |
| ---- | ------------------ | ------------------------------------------------ |
| 200  | OK                 | Request successful. The server has responded as required. |
| 301  | Moved Permanently  | Repository or user has been renamed/transferred. |
| 403  | Forbidden          | You don't have permission to access it.          |
| 404  | Not Found          | Repository doesn't exist.                        |

## Endpoint 2 — List Public Repositories for a User

**HTTP Method:** `GET`

**URL:** `https://api.github.com/users/Emilsone/repos?sort=updated&per_page=5`

**Description:** Returns a list of public repositories owned by a specific GitHub user. Supports sorting and pagination.

### Parameters

| Name     | In    | Type    | Required | Description                                                                          |
| -------- | ----- | ------- | -------- | ------------------------------------------------------------------------------------ |
| username | path  | string  | required | The GitHub username whose repos to list                                              |
| sort     | query | string  | optional | Sort by: `created`, `updated`, `pushed`, `full_name`. Default: `full_name`           |
| per_page | query | integer | optional | Page number of results to return. Default: `1`                                       |

### Example Request

```http
GET https://api.github.com/users/Emilsone/repos?sort=updated&per_page=5
```

**HTTP Method:** `GET`

**URL:** `https://api.github.com/users/Emilsone`

**Description:** Returns public information about a GitHub user, including their display name, bio, follower count, and public repository count.

### Parameters

| Name     | In   | Type   | Required | Description                                      |
| -------- | ---- | ------ | -------- | ------------------------------------------------ |
| username | path | string | required | The GitHub username of the account to retrieve   |

GET https://api.github.com/users/Emilsone
