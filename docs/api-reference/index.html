API Reference

GitHub REST API​

Base URL: https://api.github.com

Endpoint 1 — Get a Repository​

HTTP Method: GET

URL: https://api.github.com/repos/Emilsone/Nasa-image

Description: Returns detailed information about a single public GitHub repository, including its name, description, default branch, star count, fork count, open issue count, and visibility.

Parameters​

NameInTypeRequiredDescription
ownerpathstringrequiredThe username or organisation that owns the repository
repopathstringrequiredThe exact name of the repository

Example Request​

GET https://api.github.com/repos/Emilsone/Nasa-image

Example Response (200 OK)​

  "owner": {

    "gravatar_id": "",

    "html_url": "https://github.com/Emilsone",

Endpoint 2 — List Public Repositories for a User​

HTTP Method: GET

URL: https://api.github.com/users/Emilsone/repos?sort=updated&per_page=5

Description: Returns a list of public repositories owned by a specific GitHub user. Supports sorting and pagination.

Parameters​

NameInTypeRequiredDescription
usernamepathstringrequiredThe GitHub username whose repos to list
sortquerystringoptionalSort by: created, updated, pushed, full_name. Default: full_name
per_pagequeryintegeroptionalPage number of results to return. Default: 1

Example Request​

GET https://api.github.com/users/Emilsone/repos?sort=updated&per_page=5

Endpoint 3 — Get a User​

HTTP Method: GET

URL: https://api.github.com/users/Emilsone

Description: Returns public information about a GitHub user, including their display name, bio, follower count, and public repository count.
